Why I Built AetherWM

Cutting through the noise of bloated desktop stacks.

Most modern window managers and desktop environments carry an enormous amount of legacy baggage, configuration bloat, or memory overhead inherited from decades-old C and C++ codebases. Segment fault vulnerabilities, memory leaks, and overly complex configuration syntax shouldn't be the price you pay for a fast tiling workflow.

I wanted something completely transparent—a window manager where every line of code, every EWMH atom property handler, and every layout calculation is intentional and transparent. Writing it in Rust guarantees memory safety at compile-time without sacrificing the raw, bare-metal speed required for a responsive X11 session.

AetherWM exists to prove that you don't need gigabytes of background services or bloated desktop toolkits to have a rock-solid, visually clean, and lightning-fast Linux workspace.
