AetherWM

A blazingly fast, custom X11 tiling window manager written in Rust.

AetherWM is built from scratch for minimal overhead, featuring native EWMH integration, seamless Fastfetch detection, and strict resource efficiency.

Get started quickly by cloning the repository:

git clone https://github.com/azazel21t/AetherWM.git
cd AetherWM
cargo build --release
