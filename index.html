AetherWM

A blazingly fast, modern X11 tiling window manager engineered completely from scratch in Rust.
Language: Rust Protocol: X11 License: GNU GPLv3 RAM Usage: 2.2 MiB

Designed for power users and minimalists who demand absolute resource efficiency without sacrificing system responsiveness, modern layout control, or proper EWMH desktop state compliance.

What Sets AetherWM Apart?

🦀 Pure Rust Architecture

Built from the ground up utilizing Rust's strict memory safety guarantees, eliminating entire classes of undefined behavior and memory leaks common in legacy C/C++ window managers.

⚡ Native EWMH & Fastfetch Ready

Features out-of-the-box Extended Window Manager Hints (EWMH) atom implementation baked directly into the core runtime, ensuring instant, flawless system state recognition by tools like Fastfetch.

🪶 Featherlight Overhead

No heavy desktop environment daemons, no unnecessary abstraction layers. Consuming a mere 2.2 MiB of RAM, it preserves system cycles for what matters.

🛠️ Tiling Purist Control

Delivers precise master-stack layouts and predictable window management, giving you absolute control over your X11 workspace and input bindings.
